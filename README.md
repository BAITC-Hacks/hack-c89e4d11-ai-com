# FAQ-бот на 5 вопросов

Решение задачи 01 трека 03 «LLM-приложения» для репетиции HackAlem AI.

Бот работает в терминале, читает ровно 5 пар «вопрос–ответ» из `faq.txt`,
ищет ближайшую тему по ключевым словам и сходству формулировки. Если надёжного
совпадения нет, отвечает `не знаю`. RAG, модель и API-ключи не используются.

## Требования

- Python 3.10 или новее;
- внешние библиотеки не требуются.

## Запуск

```bash
python bot.py
```

Пример диалога:

```text
FAQ-бот HackAlem AI. Задайте вопрос или напишите «выход».
Вы: Когда дедлайн?
Бот: Репетиция проходит 21–22 сентября 2026 года в Астане. Рабочий слот: с 21 сентября 18:30 до 22 сентября 20:00. Обязательная сдача решения — 22 сентября до 20:00.
Вы: Какая погода?
Бот: не знаю
Вы: выход
Бот: До свидания!
```

Одноразовый запрос, удобный для быстрой проверки:

```bash
python bot.py --once "Сколько человек в команде?"
```

## Тесты

```bash
python -m unittest -v
```

Тесты проверяют загрузку пяти записей, распознавание всех пяти тем, безопасный
ответ на неизвестный вопрос, нормализацию текста и отказ при неверном числе FAQ.

## Файлы

- `bot.py` — CLI, загрузка данных и алгоритм поиска ответа;
- `faq.txt` — 5 вопросов, ответов и наборов ключевых слов в JSON-формате;
- `test_bot.py` — автоматические тесты;
- `TZ.md` — техническое задание и критерии приёмки.

## Краткий результат

Реализован автономный терминальный FAQ-бот без внешних зависимостей. Он
распознаёт переформулированные вопросы по пяти темам и не выдумывает ответ,
когда вопрос не относится к базе.

Источник условий: страница репетиции HackAlem AI в Astana Hub Education.
